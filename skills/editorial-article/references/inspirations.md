# Inspirations and provenance

These are research references, not required dependencies or claims of affiliation. Reference pages can change. No third-party templates, screenshots, site copy or benchmark numbers were bundled.

## Editorial references

- **ARKITECT / Gola**: the user's original reference showed a centered article title, a large image and a compact editorial reading layout. Reference identifier: [gola.io/ARKITECT](https://gola.io/ARKITECT). This endpoint could not be retrieved during packaging, so current contents are unverified. The user's provided visual reference informed the layout; its screenshot is not redistributed here.
- **OpenAI, GPT-6 Astra article**: [publication](https://openai.com/index/gpt-6-astra/). Useful for topic-specific headings and separating explanations, demonstrations and evaluation details. The skill does not copy its branding or make those model scores into project metrics.
- **Anthropic, Claude Fable page**: [publication](https://www.anthropic.com/claude/fable). Useful for grouping descriptions, use cases and evaluation context. It does not override the final approved appearance.

## What the final reference changed

Earlier iterations had a top wordmark, pill menu, language switcher and code-reference footer. The user removed all of them. The skill follows that final decision. English and Polish remain separate files; subtle icon feedback, the author panel, explanatory diagrams and the exclusive FAQ remain available.
