# Repository guidance

Read MAPA.md before exploring. The reusable skill lives in skills/editorial-article/. Keep the example faithful to its approved final state. It is an example, not a default project brief.

Maintain offline reading, both language files, escaped content, local font/icon licenses, the 200 ms author-panel grace period and optional components. Do not introduce a top bar, automatic publication or a backend connection.

Use the Python unit suite for renderer changes and the browser tests for interaction changes. The checker is not a substitute for browser or fact verification. Update MAPA.md when moving key files or changing the package structure.

Do not add personal machine paths, credentials or private material to commits. All design and publication decisions are recorded in the skill's `references/` files.
